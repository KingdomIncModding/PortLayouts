[b]Port Rotation - 1.0.10[/b]
Choose which sides of your Kingdom Inc nodes hold their inputs and outputs, with connections and snapping following the visible ports.

[b]Controls[/b]
[list]
[*][b]Shift + Alt + left-click[/b] a node body or label to cycle: Left/Right, Top/Bottom, Left/Top, Left/Bottom, Right/Top, Right/Bottom. Inputs are listed first.
[*][b]Alt + left-click[/b] reverses the current pair. Cycling to the next layout resets reversal.
[/list]
The building body and icon stay upright. This changes the IO layout rather than turning the whole building sideways.

[b]Ports, labels and connections[/b]
[list]
[*]Port artwork, connection snap points, hitboxes, pipe endpoints and placement previews use matching positions.
[*]Existing connections stay attached to the same inputs and outputs. Manual pipe bends are retained.
[*]Labels use an edge without ports. Top/bottom text reads normally; sideways text faces inward toward the node.
[*]Labels hide during dragging and appear when hovering over the node or its ports. The node being moved retains its own label.
[*]Layouts and reversal save per node. Native copies and Sharable Blueprints preserve them; recipients need Port Rotation to display custom layouts.
[*]Snappy's finer movement grid is supported when installed.
[/list]

[b]Expandable-slot restriction[/b]
Collector, Distributor, Manifold and Ledger keep native Left/Right ports. Shift+Alt does nothing on these buildings; plain Alt still flips them normally. Older custom layouts on them return to native sides while retaining port counts, mirroring and connections.

[b]Requirements[/b]
Kingdom Inc, Unity Mono edition, with [url=https://github.com/BepInEx/BepInEx/releases]BepInEx 5.x[/url] and its bundled Harmony. Tested on Kingdom Inc Release v1.0.12, Unity 6000.3.27f2 and BepInEx 5.4.23.6. No additional plugin is required.

[b]Installation and updating[/b]
1. Install BepInEx 5 for the Mono game if needed.
2. Close the game and extract the player ZIP into the Kingdom Inc game folder.
3. Confirm the plugin is at [b]BepInEx/plugins/PortLayouts/PortLayouts.dll[/b].
4. Start the game and use Shift+Alt+left-click on a fixed-slot node.
The existing internal plugin name and DLL remain [b]Port Layouts[/b] / [b]PortLayouts.dll[/b]. Updating replaces that file; do not install duplicate copies. Manual installation is supported; mod-manager deployment has not been tested.

[b]Compatibility and testing[/b]
Version 1.0.10 passed 2,417 isolated runtime checks and 2,497 companion checks, including Snappy, Party Node, Ledger, Leyline Conduits and Sharable Blueprints. Actual native pipe dragging/drop, UI raycasts, previews, hitboxes and committed endpoints were exercised on top/bottom and reversed layouts. Tests used disposable kingdoms with normal save loading, save writes and achievements blocked.

[b]Removal[/b]
Close the game and remove only the PortLayouts.dll file. Nodes return to native Left/Right with their native mirrored flag retained. Saving without the plugin drops custom layout metadata, so keep a save backup if you intend to reinstall and restore those layouts later.
